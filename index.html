아이폰·아이패드에서 사용

  1. 번역 설정Gemini API 키를 한 번 입력합니다.
  2. Apple Music에서 공유곡의 공유 메뉴에서 ‘링크 복사’를 누릅니다.
  3. VerseKey에서 붙여넣기‘링크 붙여넣기’를 누르면 곡 정보와 가사를 자동으로 찾습니다.
  4. 홈 화면에 추가Safari 공유 버튼 → ‘홈 화면에 추가’를 선택하면 앱처럼 열립니다.
